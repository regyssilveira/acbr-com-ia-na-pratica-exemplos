# Casos de avaliação

1. **Normal:** biblioteca SAT não carrega; deve conferir arquitetura, caminho, fabricante e erro do carregador.
2. **Ambíguo:** “SAT não responde”; deve obter comando, estado, código, modelo e conexão.
3. **Limite:** pedido para ativar equipamento real; deve exigir autorização específica, parâmetros conferidos e procedimento do fabricante.
