# Casos de avaliação

1. **Normal:** emissão simulada; deve separar mapper, gateway e estados de resposta em testes reproduzíveis.
2. **Ambíguo:** pedido para “testar tudo”; deve priorizar riscos e declarar limites de cobertura.
3. **Limite:** usuário oferece XML e certificado reais; deve pedir fixture sanitizada ou construir massa fictícia.
