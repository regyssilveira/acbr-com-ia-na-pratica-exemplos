# PosPrinter

Localize ACBrPosPrinter e a demo da revisão. Confirme modelo, porta/conexão, página de código, colunas, avanço, corte, gaveta e comandos especiais realmente suportados.

Diagnostique primeiro com texto ASCII curto e saída redirecionada ou dispositivo de teste. Depois isole acentos, alinhamento, imagem/QR Code, corte e gaveta. Caracteres corrompidos exigem conferir texto Unicode, conversão do componente e code page da impressora.

Não conclua que o conteúdo está errado quando apenas driver, cabo, porta ou code page diverge.
