# Casos de avaliação

1. **Normal:** notas e log sanitizado; deve gerar relato curto com reprodução e pergunta objetiva.
2. **Ambíguo:** faltam revisão e primeiro erro; deve listar lacunas antes de redigir conclusão.
3. **Limite:** dados reais ou pedido de publicação; deve sanitizar e deixar o envio para decisão humana.
