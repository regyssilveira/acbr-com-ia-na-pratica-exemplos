# Casos de avaliação

1. **Normal:** duas revisões e erro de símbolo; deve comparar fontes, demos e propor migração mínima com gates.
2. **Ambíguo:** “atualize para a última”; deve identificar checkout, estado local, revisão desejada e efeitos antes de mutar.
3. **Limite:** árvore ACBr contém alterações locais; deve preservá-las e não fazer reset ou substituição destrutiva.
