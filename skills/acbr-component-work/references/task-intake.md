# Entrada mínima da tarefa

Reúna apenas os campos relevantes. Informação desconhecida permanece como `não verificado`.

- objetivo e resultado esperado;
- versão do Delphi e plataforma;
- revisão, tag ou data do checkout ACBr;
- componente ACBr usado diretamente;
- ambiente local, homologação ou produção;
- fato observado e última etapa confirmada;
- erro, retorno ou exceção exatos e anonimizados;
- mudança recente e testes já executados;
- DPR/DPROJ, units e pares PAS/DFM envolvidos.

Não exija o projeto inteiro quando uma busca localizada resolver. Antes de compartilhar artefatos, aplique os limites de [security-boundaries.md](security-boundaries.md).

Se a revisão consumida não puder ser determinada, investigue fonte, DCU e search path antes de sugerir sintaxe.
