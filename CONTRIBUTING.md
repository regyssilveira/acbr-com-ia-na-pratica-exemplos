# Contribuição

Durante a preparação editorial, mudanças devem estar vinculadas a um capítulo ou a uma correção reproduzível. Informe versão do Delphi, revisão do ACBr, alvo de compilação, passos executados e resultado observado.

Não inclua fontes do ACBr, segredos, certificados nem dados fiscais reais. Código produzido com apoio de IA segue os mesmos gates do código escrito manualmente.
