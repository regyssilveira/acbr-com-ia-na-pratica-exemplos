# Segurança

Não abra issue pública contendo certificado, chave privada, senha, token, XML fiscal real, CNPJ/CPF real ou dado de contribuinte.

Os exemplos operam somente com dados fictícios e ambiente de homologação. Antes de publicar uma evidência, remova identificadores, caminhos pessoais e informações do ambiente.

Relate vulnerabilidades de forma privada pelos security advisories deste repositório.
