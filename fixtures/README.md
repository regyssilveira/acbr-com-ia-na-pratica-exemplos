# Fixtures

Dados de teste e artefatos inequivocamente fictícios. XMLs fiscais reais não devem ser adicionados sem revisão específica de segurança e direitos.

`sale-fictional.json` documenta a mesma venda construída por `TSale.Fictional`. Ela não contém CNPJ, CPF, certificado, chave de acesso ou classificação tributária e não deve ser usada em produção.
