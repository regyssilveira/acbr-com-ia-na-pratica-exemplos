# Linha de base do ambiente

## A definir antes da implementação

- versão principal do RAD Studio/Delphi;
- revisão ou data dos fontes ACBr;
- forma oficial de obtenção e instalação;
- framework de testes;
- alvos Win32 e Win64 realmente suportados;
- versão e modo de uso do SQLite;
- comandos reproduzíveis de compilação e teste.

Nenhuma versão deve ser presumida a partir de memória ou resposta de IA. Registre somente o que for conferido no ambiente usado para validar o livro.
